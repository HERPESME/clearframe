# ClearFrame

An autonomous rights-clearance department for film & TV: Gemini watches raw footage and detects every legally clearable element; a network of agents deep-researches rights holders via the Parallel Task API, scores legal risk deterministically, and produces the E&O-ready clearance dossier — with a human approving every finding.

Built for the Google Cloud "Agentic Cinema" hackathon (Parallel partner track).

See `docs/superpowers/specs/` for the design spec.
